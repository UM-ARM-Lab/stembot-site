# Project Overview

## Purpose

This repository will host the paper website for **“STEMbot: A Compliant Robot
for Under-Canopy Plant Navigation.”**

## Known Status

- The user reports that the paper was accepted to IROS 2026.
- The arXiv preprint is live at
  [arXiv:2607.07873](https://arxiv.org/abs/2607.07873), submitted on
  2026-07-08 with primary class cs.RO.
- The work is associated with a pending provisional patent.
- The conference location is Pittsburgh, Pennsylvania. Conference dates and
  final proceedings metadata are not yet recorded.
- The supplied manuscript and media have been author-cleared for public use.

## Publication Constraints

- Use only author-approved or already-public technical claims and assets.
- Treat nonpublic invention details and patent material as sensitive.
- Verify paper metadata, authors, affiliations, metrics, links, and citation
  text against primary sources before publication.

## Repository Baseline

As of 2026-07-13:

- The website is a static single-page publication site using HTML, CSS,
  JavaScript, and Bulma layout utilities.
- Raw author-provided assets are local build inputs under
  `static/new_images/`, `static/new_videos/`, and `static/paper/`.
- Browser-ready derivatives are generated under `static/media/`.
- The arXiv link and BibTeX are shown on the site; final IROS BibTeX metadata
  remains pending.
- The public code release is
  [UM-ARM-Lab/stembot](https://github.com/UM-ARM-Lab/stembot).
